photocopier-ui

Tap any departure. A blank sheet feeds up from the bottom and the scanner copies the details onto it. Use Back to slide the sheet away. The two papers come from the demo's own CSS, not from the library.

      Use it on your app

      Load dist/photocopier-ui.js (or only dist/overlay.js or dist/sheets.js), or import photocopier-ui as an ES module. Your pages and the modal keep their own backgrounds; the modal covers the app and starts with the hidden attribute.

      const overlay = PhotocopierUI.Overlay.mount(document.body, { fixed: true, level: 0.4 });
const sheets = PhotocopierUI.Sheets.create({ scanDuration: 2600, feedDuration: 700, closeDuration: 500 });

row.addEventListener('click', () => {
  fillDetails(row.dataset.id);
  sheets.present(details);   // blank sheet slides up, then the scan reveals it
});
backButton.addEventListener('click', () => sheets.dismiss(details));   // slides down
